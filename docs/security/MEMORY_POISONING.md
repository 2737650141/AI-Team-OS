# Memory poisoning controls

Uploaded documents, tool output, web pages, task results, system observations, and model inference are untrusted for semantic-user and procedural-preference writes. They cannot impersonate an explicit user statement.

Repeated preference detection requires at least three distinct tasks spread across at least one hour and still creates a proposal only. It cannot activate a preference. Sensitive/personality profiling is prohibited.

Policy order is deterministic: secret scan, privacy rejection/quarantine, sensitive-topic quarantine, external-source restriction, trusted-user-source check. Tests cover prompt-injection text, credential patterns, project/user isolation, and checkpoint resurrection.
