# Memory Center

`/memory` is the user control surface for long-term memory. It shows active count, pending confirmations, project count, type tabs, search, project scope, source, version, privacy, last use, and “why the system knows.”

Proposals support Confirm, Edit and Confirm, and Reject. Active records support a destructive Forget action with an explicit explanation that content is erased and cannot return from old tasks. Export downloads safe JSON. Memory controls can disable retrieval/proposals and repeated-preference detection.

Task Detail contains a Memory Context section listing the role, fact, scope, selected reason, version, and token estimate used for that run. Both Chinese and English UI copy are present.

Settings → Connections includes any number of custom OpenAI-compatible Providers. Add/Manage supports base URL, credential storage, connection test, model discovery/refresh, model search, default model, per-role routing, credential replacement/removal, default marker, and provider deletion.
